# Changelog

All notable changes to Qubee are documented here. This project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0]

Qubee 1.0.0 is the initial release of the Qubee brand, based on the open-source multi-agent interactive classroom platform (MIT-licensed).

### Highlights

- 🤖 **Agent workbench** — a chat-first workspace that plans, builds, and revises whole courses
- 💾 **Durable sessions** — server-backed runs survive restarts; cancel, resume, and steer anytime
- 📎 **Session materials** — upload documents, audio, and video, or pull from web search
- 🧰 **Course tools + built-in skills** — slides, quizzes, interactives, PBL, images, video, voices, `.pptx` import
- 🔌 **Provider-neutral by design** — bring your own models, media, search providers, and storage backend
- 📦 **`@qubee/*` SDK** — DSL, renderer, editor, importer, generation, and storage packages
